10. REPRODUCTION
----------------

Depuis la racine du projet, avec l'environnement virtuel:

    .venv\Scripts\python.exe src/model/compute_metrics.py

Le script recharge les CSV, applique le meme preprocessing, reconstruit le
split stratifie random_state=42, charge l'artefact, calcule les metriques et
met a jour:

    models/os_classifier_metrics.json

Pour la validation independante, apres avoir place des PCAP dans pcaps/:

    .venv\Scripts\python.exe src/model/validate_model.py

L'interface web affiche automatiquement le JSON enrichi dans l'onglet Model
Metrics via:

    .venv\Scripts\python.exe dashboard/app.py

Puis ouvrir http://127.0.0.1:5000.
